# Savio Dominic Juma — Portfolio

A modern, responsive personal portfolio website built with **HTML, CSS, and vanilla JavaScript**. It showcases my skills, projects, background, and includes a blog and testimonials section.

## ✨ Features

- **Responsive Design** – Adapts seamlessly from mobile to desktop.
- **Modern Layout** – Clean sections for Hero, About, Gallery, Projects, Testimonials, Blog, and Contact.
- **Interactive Navigation** – Mobile-friendly menu toggle.
- **Smooth Scrolling** – Anchor links for easy navigation.
- **Gallery Showcase** – Displays multiple portrait images in a grid layout.
- **Projects Section** – Highlights featured work with tech tags and hover overlays.
- **Testimonials Slider** – Interactive slider to showcase client feedback.
- **Blog Section** – Displays latest articles with categories and read-time.
- **Back to Top Button** – Appears on scroll for easy navigation.

## 🛠️ Built With

- **HTML5** – Semantic structure.
- **CSS3** – Custom properties (variables), Flexbox, Grid, animations, and transitions.
- **JavaScript** – For the mobile menu, back-to-top button, and testimonial slider.
- **Google Fonts** – *Poppins* and *Montserrat*.
- **Material Icons** – For UI icons.
